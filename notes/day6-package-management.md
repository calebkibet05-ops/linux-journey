# Day 6 – Fedora Package Management

## Package manager

Fedora uses `dnf` to search for, install, update, and remove software.

## Commands practiced

- dnf search
- dnf info
- dnf install
- dnf remove
- dnf list installed
- dnf provides
- dnf repolist
- dnf history
- dnf check-update

## Key lessons

- Repositories provide trusted software packages.
- Package details should be reviewed before installation.
- `dnf history` helps audit package changes.
- Keeping packages updated improves security and reliability.
