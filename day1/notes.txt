## Mission

Set up a Fedora Linux workspace for the 30-Day Systems Engineering Bootcamp and initialize a professional Git repository.

## Commands Practiced

cat /etc/fedora-release
hostnamectl
whoami
pwd
mkdir -p ~/linux-journey/{notes,labs,scripts}
tree ~/linux-journey

## What I Learned

- Fedora uses `dnf` for package management.
- `hostnamectl` displays system identity information.
- `pwd` shows the current working directory.
- `mkdir -p` creates nested directories in one command.
- `tree` helps visualize a project's folder structure.
